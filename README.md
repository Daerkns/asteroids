# Asteroids

A simple **Asteroids-style arcade game built with Python and Pygame**.

## Features

- Player movement and rotation
- Shooting with cooldown
- Random asteroid spawning
- Multiple asteroid sizes
- Asteroid splitting on destruction
- Circular collision detection
- Sprite-based game architecture

## Controls

| Key | Action |
|---|---|
| `W` | Move forward |
| `S` | Move backward |
| `A` | Rotate left |
| `D` | Rotate right |
| `Space` | Shoot |

## Running

Install Pygame:

```bash
pip install pygame
```

Then run:

```bash
python main.py
```
